## 🛍️ About the Project

**SupaStore** is a modern e-commerce application built with **Flutter and Dart**, designed to provide a seamless and responsive shopping experience across mobile and desktop platforms.

The project uses **Supabase** as its backend infrastructure and follows **Clean Architecture** principles to ensure a scalable, maintainable, and well-structured codebase.

SupaStore includes a complete shopping experience for customers, alongside a dedicated admin dashboard for managing products, orders, categories, users, and store settings.

### ✨ Key Highlights

- 📱 **Cross-Platform:** Responsive UI for mobile and desktop.
- 🛒 **E-Commerce:** Product browsing, search, filtering, cart, favorites, and checkout.
- 🔐 **Authentication:** Secure user authentication and demo access.
- 🛠️ **Admin Dashboard:** Comprehensive store management tools.
- ☁️ **Backend:** Supabase integration for database, authentication, and storage.
- 🏗️ **Architecture:** Clean Architecture with a modular and maintainable structure.

### 🎯 Project Goals

SupaStore was developed as a practical project to demonstrate Flutter development skills, responsive UI design, backend integration, state management, and scalable software architecture.

The project also serves as a portfolio project showcasing the implementation of a real-world e-commerce application.

## 🛠️ Tech Stack & Architecture

SupaStore is built using Flutter and Dart, following a modular and maintainable architecture with a focus on scalability, code reusability, and responsive user interfaces.

### 💻 Core Technologies

| Technology | Purpose |
|---|---|
| Flutter & Dart | Cross-platform application development |
| Supabase | Backend, authentication, database, and storage |
| Git | Version control and source code management |

### 🏗️ Architecture & State Management

| Technology | Purpose |
|---|---|
| Clean Architecture | Separation of presentation, domain, and data layers |
| Provider | State management |
| GetIt | Dependency injection |
| GoRouter | Declarative navigation and routing |
| Responsive Design Patterns | Adaptive layouts for mobile, tablet, and desktop |

### 📦 Packages & Libraries

**Networking & Backend**
- `http` – HTTP requests and API communication
- `supabase_flutter` – Supabase integration
- `connectivity_plus` – Network connectivity monitoring
- `app_links` – Deep linking and app link handling

**UI & User Experience**
- `flutter_screenutil` – Responsive sizing and screen adaptation
- `cached_network_image` – Network image caching
- `shimmer` – Loading placeholders and skeleton effects
- `carousel_slider` – Image and content carousels
- `smooth_page_indicator` – Carousel page indicators
- `flutter_rating_bar` – Product rating components
- `flutter_svg` – SVG rendering
- `iconsax_flutter` – Icon library
- `pinput` – OTP input fields

**Storage & Utilities**
- `shared_preferences` – Local key-value storage
- `flutter_dotenv` – Environment variable configuration
- `intl` – Date, number, and localization formatting
- `persian_number_utility` – Persian number and date utilities

**Media & External Integrations**
- `image_picker` – Image selection
- `flutter_image_compress` – Image compression
- `url_launcher` – Opening external URLs

**Data Visualization**
- `fl_chart` – Charts and dashboard analytics

### 📐 Design & Development Principles

- Clean and modular code organization
- Separation of concerns
- Reusable UI components
- Responsive layouts for different screen sizes
- Dependency injection
- Centralized state management
- Scalable feature-based project structure
